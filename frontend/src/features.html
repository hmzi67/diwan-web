Features

Diwan is built for one job: ringing up a sale as fast as you can type it. Everything below ships in every licence — there are no feature gates between the Starter, Standard and Enterprise editions, only limits on how many terminals and branches you run.

At the counter

Core

The billing screen is keyboard-first. Quick items are bound to the number keys, orders are placed with a chord, and tokens print without opening a menu — so a queue moves at typing speed rather than mouse speed.

Feature 01

Keyboard-first billing

Nine quick-item slots on keys 1–9, a running bill that updates as you type, and no mouse required to close a sale.

  • Quick items on keys 1–9
  • Ctrl + Enter places the order
  • Ctrl + K prints the token
See the billing screen

Feature 02

Tables, tokens & bills

Open a bill against a table, print a token for the customer, and keep several tables in flight at once without losing the running total.

  • Per-table running bills
  • Instant token printing
  • Switch tables from the keyboard
Platform builds

Feature 03

Receipt & kitchen printers

Print customer receipts and kitchen chits from the same terminal. Included from the Standard edition upward.

  • Receipt printer support
  • Kitchen / order chit printing
  • USB and network printers
See pricing

Stock & numbers

Core

Billing is only half a till. Diwan keeps stock and totals alongside it, so the count on the shelf and the count on the screen stay the same number.

Feature 04

Billing & inventory

Every sale decrements stock as it is rung up. Core billing and inventory are in the Starter edition, not an upgrade.

  • Item and price management
  • Stock decremented per sale
  • One branch, one terminal on Starter
What each edition includes

Feature 05

Reporting

Sales, shifts and totals after the fact — the numbers you need to reconcile a day's takings. Included from Standard upward.

  • Sales and shift totals
  • All core modules included
  • Reconciliation after close
Compare editions

Feature 06

Offline-first

The till keeps working when the internet does not. Nothing is held hostage to a connection, because a dropped line should not stop a sale.

  • Sells without a connection
  • Sync resumes when the line returns
  • One-time online activation only
How activation works

Licence & platforms

Included with every licence

One key, three platforms, one payment. What you buy is a licence — the installs, the activation and the updates ride along with it.

Feature 07

Windows, macOS & Android

The same licence key unlocks all three builds, so the counter runs on Windows and a handheld runs on Android from one purchase.

  • Windows 10 or later, 64-bit
  • macOS 11 or later, universal
  • Android 8.0 or later
Platform builds

Feature 08

Activate once, then run offline

Activation happens online, once, on first launch. After that Diwan does not phone home — one device per licence key.

  • One-time online activation
  • One device per key
  • Manual device moves on request
Moving devices

Feature 09

Updates with the key you have

New versions ship as updated installers and are fetched with the same licence key — no repurchase, no renewal, no subscription.

  • Downloaded with your existing key
  • Free software updates
  • One-time payment, no renewal
